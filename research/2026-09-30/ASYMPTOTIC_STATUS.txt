ORIGINAL QUESTIONS

1. Minimum total size A_n: OPEN.
   exp(Omega(n)) <= A_n <= exp(O(n log n)); neither gap-closing direction
   has been proved. The C(n!)^2 equal-face construction improves an explicit
   construction, not this asymptotic order.

2. Polynomial equalization E_n <= A_n^C: OPEN.
   The elementary combination of already known absolute size bounds gives
   E_n <= A_n^{O(log n)} = A_n^{O(log log A_n)}.
   This is a synthesis of known bounds, not a new equalization algorithm.
   Method-specific obstructions do not disprove polynomial equalization.

3. Every individual die exponential: FALSE.
   If g(n) minimizes the size of one specified die while allowing the others
   any finite sizes, then g(n)=Theta(n^2). Every die has >=c n^2 faces, and
   every integer K>=C n^2 can be prescribed as the specified die's exact size.
   The remaining n-1 dice can have a common, possibly enormous, finite size.
   Guide: size_bounds/QUADRATIC_PROOF_GUIDE.txt.
   Main lower proof: independent_directions/elementary_quadratic_atom_bound.tex.
   Final simplification: a self-contained Gaussian/Radau paired-threshold
   argument proves each last coordinate >=1-pi^2/(m+1)^2 and terminal
   weight <=200/m^2. Thus each die has >=(n-1)^2/200 faces. Three full
   independent internal reviews passed. The long analytic lower proof
   is no longer needed for this theorem; its inputs remain relevant to
   the separate profile branch.
   Upper proof:
   size_bounds/polynomial_exceptional_die.tex;
   rational_designs/asymptotic/every_large_exceptional_size.tex.
   Lower-bound hypothesis can be weakened to exact winning probabilities
   for all subsets containing the distinguished die.

MORE SMALL DICE

For every fixed k, k specified dice can have the same polynomial number
of faces. More uniformly, for every n>k>=1,
    S <= (n+2^k+2)^{exp(C k^2)}
for an absolute C. All n dice are finite and permutation-fair; the other
n-k dice can share a much larger finite count.
Consequences: k=floor(c sqrt(log n)) permits S<=exp(sqrt n), and
k=o(sqrt(log n)) permits S<=exp(n^{o(1)}).
This does not give n^C for a growing k with one fixed exponent C.
The initial common denominator lcm(1,...,2^k) is explicitly charged;
uncontrolled high polynomial-coefficient denominators do not enter S.
Guides: independent_directions/FIXED_K_PROOF_GUIDE.txt;
size_bounds/FIXED_K_PROOF_GUIDE.txt.
Main uniform theorem: size_bounds/uniform_fixed_number_complexity.tex.

OPTIMAL BOUNDED ENDPOINT PROFILE

For arbitrary positive-weight monotone tensors with exact mixed moments,
put s=sum_i(1-p_i), with m columns. For each fixed L,
    max_i |m(1-p_i)-s| <= C_L R_m(s),  0<=s<=L,
    R_m(s)=min{m s, sqrt(s/m)+1/m}.
For every positive scale lambda<=L, actual finite uniform fair dice have
a row with s comparable to lambda and deviation >=c_L R_m(lambda).
The comparison constants are uniform in m and lambda. Exact prescribed s
and efficient face counts are not asserted by these sharpness examples.
Consequently relative synchronization holds uniformly when ms tends to
infinity, and this threshold cannot be weakened in general.

For arbitrary positive row weights, also
    w_q <= C_L (sqrt(s_q)/m^{3/2} + 1/m^2),  0<=s_q<=L.
Matching examples for this atom bound are proved in the weighted tensor
class; matching face counts of actual uniform dice are not claimed.
