Proof guide: several specified dice with controlled counts

Strongest reviewed quantitative theorem:
  uniform_fixed_number_complexity.tex
For all n>k>=1, there is a fully permutation-fair n-die family in
which k specified dice have the SAME count
  S <= (n+2^k+2)^(exp(C k^2)).
The remaining n-k dice are equal-sized and finite; their count is
not bounded in this theorem.

Consequences:
- Every fixed k admits polynomial specified counts.
- For some absolute c>0, k=floor(c sqrt(log n)) admits S<=exp(sqrt n).
- If k=o(sqrt(log n)), the specified counts are exp(n^{o(1)}).

Read the qualitative global mechanism first:
  ../independent_directions/fixed_number_polynomial_dice.tex
Keep the special densities on disjoint pure cells of a uniform grid.
Insert one new uniform variable by replacing, inside each cell, the
single active old density together with that uniform by a local pair.
At most one old variable shares a cell with the new variable, so all
ordered integrals reduce to local two-variable identities.

The arithmetic obstacle is a common denominator across many cells.
The local construction uses one universal finite set of control
FEATURE columns. Their rational matrix is identical in every cell,
so low-moment corrections have one common denominator. On uniform-grid
coordinates, K times each normalized input moment has its old cell-mass
normalization canceled exactly.
