\section{Introduction}

\begin{definition}
A string is fair if it corresponds to a fair dice. E.g. If the alphabet is ABC, all permutations ABC, ACB, ... should have the same number of occurences.   
\end{definition}

\begin{definition}
A string is super-fair if, in case of ABC alphabet, we have $\#A = \#B = \#C$, $\#AB = \#BA = \#AC = ...$ and then the fair condition.  
\end{definition}

\begin{lemma}
A concatenation $S_1 \circ S_2$ of two super-fair strings is super-fair.
\end{lemma}

A variant of this lemma can be used inductively in our construction. 

\begin{theorem}
There exists a super-fair string over $n$ letter alphabet with number of letters $n \cdot (n!)^{n-1}$. 
\end{theorem}

It is not true that a concatenation of two fair strings is fair. E.g. ABA is fair, BAB is fair, but ABABAB is not fair. But we at least have the following lemma.  

\begin{lemma}
If $S$ is fair, then $S\circ S$ is fair. This relies on the equations of the type $AB\cdot C = AC \cdot B$. 
\end{lemma}
\begin{proof}
We need to count terms like $\#AB \cdot \#C$. This is actually equal to $\#CAB + \#ACB + \#ABC = 3\#ABC$ where the equality is by fairness. So these calculations give the same result for all starting permutations and this implies that $S \circ S$ is fair. 
\end{proof}

A variant of this lemma is used in Eric's construction. 

\begin{lemma}
In Eric's construction if we go from ABC to ABCD, we have e.g. that $\#ABCD = \#BACD$. 
\end{lemma}
\begin{proof}
This follows from the equations of the type $AB\cdot C = AC \cdot B$. 
\end{proof}

\begin{theorem}
Eric's construction works provided that all corresponding Cotesian numbers are nonnegative. 
\end{theorem}
\begin{proof}
Because of the above lemma, we only need to prove that $\#D*** = \#*D** = \#**D* = \#***D$. This should lead to bernshteyn polynomials. 
\end{proof}

\begin{theorem}
For any $n$ fair dice, at least $(1-\eps)$ fraction of them has to have at least $2^{\Omega(\eps n)}$ sides. 
\end{theorem}


Cotesian numbers make lot of sense because we are basically approximating the continuous analogue. In particulart the fact that the integral of the bernshteyn polynomial is what it is follows directly from what happens in the continuous process.
